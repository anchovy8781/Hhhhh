# 전력기기 랩 (Jeonryeok Lab)

재료를 고르고 슬라이더를 움직이면 **인덕터·변압기·솔레노이드·DC 모터**가 3D로 조립되고
성능이 즉시 계산되는 안드로이드 앱입니다.

LTspice와 같은 회로 시뮬레이터는 넷리스트와 부품 모델을 먼저 만들어야 답이 나옵니다.
이 앱은 반대로 갑니다 — **회로도도 넷리스트도 없습니다.** 코어 재료와 치수, 턴수,
전선 굵기 같은 *물리적인 것*을 직접 만지면 인덕턴스·포화 전류·손실·온도가 바로 나오고,
설계가 망가지면 무엇을 어떻게 고쳐야 하는지 한국어로 알려줍니다.

```
피크 전류 3.45 A가 포화 전류 0.16 A를 넘습니다. 공극을 넣거나 턴수를 줄이세요.
이 전압·주파수에서는 1차 턴수가 최소 612턴 필요합니다. 지금은 480턴입니다.
고정자 요크가 포화해 자속이 34% 잘렸습니다. 요크를 12.4mm 이상으로 키우면 자석 성능을 다 씁니다.
```

## APK 받기

이 저장소를 푸시하면 GitHub Actions가 테스트를 돌리고 APK를 만듭니다.

1. GitHub 저장소 → **Actions** → **Android APK** 워크플로
2. 최신 실행 → 아래 **Artifacts** → `jeonryeok-lab-debug-apk` 다운로드
3. 압축을 풀고 `app-debug.apk`를 안드로이드 기기에 설치
   (설정 → 보안 → *출처를 알 수 없는 앱 설치* 허용 필요)

디버그 서명 APK라 그대로 설치됩니다. 스토어 배포용 release APK는 별도 서명 키가 필요합니다.

## 브라우저에서 바로 써보기

```bash
cd app
npm install
npm run dev      # http://localhost:5173
```

APK와 완전히 같은 화면입니다. 안드로이드 껍데기는 Capacitor가 씌웁니다.

## 전원을 직접 걸어보기

정상 상태 계산은 "이 설계가 어디로 수렴하는가"를 알려주지, "거기까지 가는가"는
알려주지 않습니다. **전원 인가** 버튼을 누르면 실제로 돌려봅니다.

```
80.1초 만에 보빈이(가) 고장났습니다
  돌입 최대 전류   1.73 A       권선 최종 온도   308°C / 한계 155°C
  전류 상승 시간   1.0ms        코어 최종 온도   271°C / 한계 200°C
                               보빈 최종 온도   283°C / 한계 155°C

⛔ 보빈 · 절연물 한계 초과            [보빈]
   80.1초에 보빈·절연물이 168°C에 도달해 보빈 재료 내열 155°C를 넘었습니다.
   보빈이 변형되면 권선이 풀리고 절연 거리가 무너집니다.
   → PPS·LCP 같은 고온 등급 보빈으로 바꾸세요.
```

**어느 부품이 언제 왜 고장났는지**를 지목합니다. 권선·코어·자석·보빈·하우징이
각자 자기 열용량과 한계를 갖고 따로 데워지므로, 얇은 보빈이 두꺼운 권선보다
먼저 타는 것 같은 실제 순서가 그대로 나옵니다.

전기 과도와 열 과도는 시간 규모가 100만 배 차이나므로 따로 적분합니다 —
돌입 전류는 자기 시간 규모(ms)에서, 온도는 자기 시간 규모(분)에서. 30분을 끝까지
돌리면 정상 상태 분석과 정확히 같은 곳에 도착합니다. 두 화면이 서로 다른 말을
하는 일은 없습니다.

바로 보입니다.

## 실제 가동환경

같은 권선이라도 25°C 개방 벤치와 55°C 밀폐 함체에서는 다른 물건입니다.

- **주위 온도** −55 ~ 125°C
- **냉각 방식** 16종 — 자연 공랭(h≈12)부터 2상 침지(h≈1500 W/m²K)까지
- **함체** 개방 / 통풍 / 밀폐 / 포팅 — 밀폐는 대류와 **복사를 함께** 깎습니다
- **고도** — 표준 대기 밀도비. 12km 상공은 공기가 1/4이라 대류가 거의 없습니다
- **듀티** — 간헐 운전이면 같은 설계로 훨씬 큰 출력을 낼 수 있습니다
- **표면 방사율** — 광택 금속 0.1 vs 흑색 도장 0.95

### 용도 20종

실험실, 소비자 가전, 산업용, 자동차 실내·엔진룸, 전기차 파워트레인, 태양광
인버터, 서버 전원, 항공, 우주, 의료, 철도, 선박, 군용, 옥외 통신, 용접기,
유도가열, 무선충전, LED 드라이버, 계측기.

용도를 고르면 그 환경이 적용되고, **그 분야의 요구조건으로 설계를 검사**합니다 —
허용 온도, 절연 등급, 포화 여유, 목표 효율. 벤치에서 멀쩡하던 설계가 엔진룸
프로파일에서는 즉시 탈락합니다.

## 설계 상세 조정

- 슬라이더 옆 숫자를 누르면 **정확한 값을 직접 입력**할 수 있습니다
- 주파수처럼 50Hz~2MHz를 오가는 값은 로그 슬라이더로 전 구간을 다룹니다
- 파라미터는 재료 · 치수 · 권선 · 운전 · 환경 다섯 묶음으로 나뉩니다
- 권선 절연 등급을 따로 고릅니다. 설계가 견디는 온도를 정하는 건 구리가 아니라
  에나멜이고, 가장 싸게 올릴 수 있는 것도 그쪽입니다

## 물리 모델

숫자가 그럴듯해 보이기만 하면 아무 의미가 없으므로, 각 계산의 근거를 밝힙니다.

- **자기회로** — 코어와 공극을 직렬로 두고 암페어 법칙 `NI = H_core·l_e + B·g/µ0`을
  이분법으로 풉니다. B-H 곡선은 `H(B) = B/(µ0·µ_r) / (1 − (B/Bsat)^n)`이며
  지수 `n`이 니 곡선의 날카로움입니다. 페라이트·강판은 `n=8`(포화 직전까지 투자율 유지 후 급락),
  분말 코어는 `n=2`(분산 공극이라 낮은 자속부터 서서히 감소). 이 한 개의 지수가
  "잘 버티다 갑자기 무너짐"과 "일찍부터 서서히 줄어듦"을 가릅니다.
- **포화 전류** — 데이터시트 관례대로 **인덕턴스가 초기값의 70%로 떨어지는 전류**입니다.
  "B가 정확히 Bsat이 되는 전류"로 정의하면 어떤 현실적인 B-H 곡선에서도 발산하므로,
  그 값은 곡선을 어디서 잘랐는지에만 의존하게 됩니다.
- **철손** — 슈타인메츠 `Pv = k·f^α·B^β`. `k`는 재료마다 **데이터시트 기준점**
  (예: N87은 100kHz·200mT에서 375 kW/m³)에서 역산하므로 원 자료와 대조할 수 있습니다.
- **구리손** — 온도 보정 비저항에 다우웰(Dowell)의 표피·근접 효과 계수를 곱합니다.
  층수는 창 높이와 전선 굵기에서 계산합니다.
- **열** — 자연대류(`h ∝ ΔT^0.25`)와 복사(`εσ(Ts²+Ta²)(Ts+Ta)`)를 합칩니다.
  손실과 온도는 서로를 밀어올리므로(구리 저항은 0.4%/K씩 상승) 반복 수렴시킵니다.
  고정 계수 모델은 100K 근처에서만 맞고 그 위에서는 실제보다 수백 도 높게 예측합니다.
- **전원 인가** — 전기 과도(RL 또는 관성 포함 모터)와 열 과도를 각자의 시간
  규모에서 적분합니다. 부품마다 질량×비열로 열용량을 갖고, 순간 손실이 만드는
  목표 온도를 향해 1차 지연으로 따라갑니다. 전압 구동(솔레노이드·모터: 뜨거워지면
  전류가 준다)과 전류 구동(컨버터 속 인덕터: 제어 루프가 전류를 유지하므로 저항
  증가가 그대로 열이 된다)을 구분합니다 — 같게 다루면 둘 중 하나는 반대가 됩니다.
- **모터** — 자석 부하선에서 공극 자속밀도를 구하고 누설 10%를 뺀 뒤,
  **고정자 요크 포화가 자속을 제한**하도록 결합했습니다(자석을 키워도 토크가 안 느는
  가장 흔한 이유입니다). 브러시 전압강하와 속도에 비례하는 회전자 철손도 포함합니다.

### 이 앱이 하지 않는 것

- **과도 응답 시뮬레이션이 없습니다.** 스위칭 파형, 링잉, 기동 전류 파형은 계산하지 않습니다.
  그런 게 필요하면 LTspice가 맞는 도구입니다.
- **임의 회로를 못 만듭니다.** 정해진 4가지 장치의 설계 파라미터만 다룹니다.
- **1차원 자기회로 근사입니다.** 유한요소해석이 아니므로 국부 포화, 복잡한 공극 형상,
  비대칭 누설은 잡아내지 못합니다.
- **누설 인덕턴스를 계산하지 않습니다.** 커먼모드 초크만 결합률을 입력받습니다.
- **재료 데이터는 계열 대표값입니다.** 특정 제조사의 특정 로트가 아닙니다.
  실제 구매 전에는 해당 데이터시트로 확인하세요.
- **부품 간 열 결합은 1차 근사입니다.** 각 부품이 자기 열용량으로 데워질 뿐,
  권선→코어 전도 경로를 따로 풀지는 않습니다.
- 계산값은 **설계 감각을 잡기 위한 1차 근사**입니다. 실제 제작 전에는 측정하세요.

## 구조

```
src/physics/          측정 가능한 것들 — UI도 3D도 모르는 순수 계산
  catalog/            1,146종 카탈로그 생성기 + 검색 (계열 → 변종 유도)
  materials.ts        재료 조회와 물성 함수 (구버전 id 별칭 포함)
  magnetics.ts        자기회로 solver, B-H 곡선, 인덕턴스, 포화
  wire.ts             AWG 환산, 표피 깊이, 다우웰 AC 저항
  thermal.ts          냉각 방식 + 복사, 손실↔온도 반복 수렴
  environment.ts      주위온도·냉각·함체·고도·듀티
  applications.ts     용도 20종과 그 요구조건 검사
  run.ts              전원 인가 과도 시뮬레이션과 부품별 고장 진단
  devices/            7개 장치 모델 (파라미터 정의 + simulate())
src/view3d/           Three.js — BuildSpec을 받아 형상을 생성
src/ui/               슬라이더, 결과 카드, 경고, 곡선, 프리셋
tools/smoke.mjs       헤드리스 Chromium으로 실제 앱을 조작하는 검증
android/              Capacitor가 만든 네이티브 프로젝트
```

물리 엔진은 브라우저에 의존하지 않으므로 Node에서 그대로 테스트됩니다.
3D 뷰는 `BuildSpec`(치수와 색상만 담긴 평범한 객체)만 받으므로 물리와 분리됩니다.

## 테스트

```bash
npm run typecheck   # 타입 검사
npm test            # 물리 엔진 단위 테스트 156개
npm run build       # 프로덕션 번들
node tools/smoke.mjs   # 실제 브라우저에서 7개 장치 · 검색 · 전원 인가 검증
```

단위 테스트는 알려진 값과 대조합니다 — AWG 규격 지름, 100kHz 구리 표피 깊이 0.206mm,
공심 토로이드 인덕턴스 공식, **1,146종 전 항목이 자기 데이터시트 기준점을 재현하는지**,
표준 대기 밀도비, 턴수 제곱 비례, 공극에 따른 포화 전류 증가, 부하에 따른 전압 강하,
그리고 전원 인가 후 30분이 정상 상태 분석과 같은 곳에 도착하는지.

스모크 테스트는 브라우저에서만 실패하는 것을 잡습니다 — WebGL이 실제로 픽셀을 그렸는지,
7개 장치가 전부 예외 없이 전환되는지, 검색이 목록을 실제로 좁히는지,
전원 인가가 판정과 조치를 내놓는지, 그리고 **함께 제공되는 기본값과 프리셋이
전부 자기 한계 안에 있는지**.

## 기술 선택

- **Three.js + WebGL** — 절차적 형상 생성. 치수를 바꾸면 형상이 그대로 따라옵니다.
- **Capacitor** — 웹 앱을 APK로 포장. 같은 코드가 브라우저와 안드로이드에서 동일하게 동작합니다.
- **의존성 없는 물리 엔진** — 순수 TypeScript. 수식을 읽고 검산할 수 있습니다.
